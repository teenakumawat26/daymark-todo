# Daymark - Minimal To-Do List ✨

A clean, minimal and motivational to-do app to organize your daily tasks.

**Live Demo:** https://teenakumawat26.github.io/daymark-todo/

### Features
- ✅ Add, delete and strike-through tasks
- ⭐ Star important tasks - starred tasks move to top
- 🎉 "Shabash!" motivation popup on task completion
- 📅 Today's date display
- 💾 Saves tasks in browser (LocalStorage)

### Tech Stack
- HTML5
- CSS3 (Glassmorphism UI)
- Vanilla JavaScript
